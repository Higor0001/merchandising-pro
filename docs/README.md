# MERCHANDISING PRO
Sistema Inteligente de Gestão e Execução de Merchandising no Varejo

## Estrutura de Pastas
- `backend/`: API Node.js + Express + SQLite (`node:sqlite`), autenticação JWT, upload de fotos e módulo de IA.
- `frontend/`: Aplicação React + TypeScript + Tailwind CSS + PWA (instalável e com fila offline).
- `docs/`: Documentação técnica do projeto.
- `scripts/`: Scripts de inicialização rápida.

## Como Iniciar
Execute `scripts/iniciar-sistema.bat` ou rode:
```bash
cd backend
npm start
```
Acesse no navegador (desktop ou smartphone): `http://localhost:3001`
